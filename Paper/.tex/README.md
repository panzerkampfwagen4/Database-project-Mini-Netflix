# Mini-Netflix report (Overleaf)

Upload all files in this folder to a new Overleaf project. Set **main.tex** as the main file and choose **XeLaTeX** as compiler. The two PDF diagrams are already compiled; their editable TikZ sources are in `diagrams/`. The Noto fonts and their OFL licenses are in `fonts/`.

`body.tex` was converted from the supplied DOCX with Pandoc. Escaped LaTeX formulas from Word were restored, SQL was formatted in framed listings, and the requested Due Date line was removed. Both vector diagrams are embedded at the text width within the report flow. The English cover follows the supplied `bia.pdf` layout and uses its PTIT logo, with title, names and IDs from the DOCX.
