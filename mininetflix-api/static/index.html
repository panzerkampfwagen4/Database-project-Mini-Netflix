Membership & Billing Center

Manage subscription tiers, renew past-due billing, and manage multi-profile entitlements.

Billing States Defined:

ACTIVE: Paid and authorized. Full streaming access permitted.
SUSPENDED: Overdue invoice. Stream requests blocked with HTTP 402 until invoice renewed.
CANCELLED: Account terminated by user.

Business Rules Compliance Suite

Direct execution tests designed for examination committee evaluation of relational constraints (BR-01 to BR-05).

BR-01

Subscription Tier Access Control

Enforces that profiles may only query and view catalog items where minimum_tier_id ≤ current_tier_id.

BR-02

Concurrent Stream Threshold Limit

Enforces that active concurrent playback sessions cannot exceed the subscription stream cap (e.g. Standard allows max 2 streams). Spawning stream #3 triggers HTTP 409 Conflict.

BR-03

Profile Data Isolation

Verifies that watchlists, ratings, and viewing history remain strictly isolated between profiles under the same tenant account via composite foreign keys.

BR-04

Kids Profile Parental Restrictions

Verifies that profiles marked with is_kids_profile = true are strictly filtered to exclude all mature content dually classified as R or NC-17.

BR-05

Account Profile Threshold (1 ≤ N ≤ 5)

Enforces cardinality constraint where an account cannot exceed 5 profiles. Creating a 6th profile triggers HTTP 409 Conflict.

Dataset Provenance & Schema Normalization

Technical disclosure on empirical data ingested from HuggingFace and mapped to 3NF schema.

Primary Dataset Citation

Source: hugginglearners/netflix-shows (Netflix Movies and TV Shows Dataset). Comprising 8,807 production records cataloging international titles, runtime durations, maturity classifications, and synopses.

Transformation & Relational Alignment

Dataset Ingest Attribute Relational Target Column Normalization & Engineering Rationale
type ("Movie", "TV Show") catalog_title.content_type Transformed "TV Show" → 'Series' to align with ENUM('Movie', 'Series').
rating (TV-MA, TV-14, TV-PG...) catalog_title.maturity_rating Harmonized TV broadcast codes into canonical ratings:
• TV-MA, UR → R (Mature Audiences)
• TV-14 → PG-13 (Parents Strongly Cautioned)
• TV-PG, NR → PG (Parental Guidance)
• TV-Y, TV-Y7, TV-G → G (General / Children)
duration ("90 min", "2 Seasons") streamable_media_unit & tv_series Movies converted to total seconds (min * 60). Series decomposed hierarchically into seasons and episodes.
(Synthesized Entity) subscription_tier Engineered 4 subscription tiers (Free, Basic, Standard, Premium) with stream allowances (1, 2, 4) to evaluate BR-01 and BR-02.

RESTful Microservice Specifications

All endpoints adhere strictly to REST architectural standards and output application/json.

HTTP Method Resource Path Business Operation Primary Parameters
GET /api/catalog Browse catalog filtered by tier access (BR-01) and parental safety (BR-04) profile_id, type, search
